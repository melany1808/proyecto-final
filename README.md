
#                                                                Café Altiplano 
## Mapa del sitio

index.html:  Es la página principal.
carta.html: Donde estan los productos y precios.
sedes.html: Es la información de las sedes.
reservas.html: Es el formulario para las reservas.
css/: Estan  las cinco hojas de estilos.
imagenes/: Esta la carpeta destinada a las imágenes.
README.md: Donde esta la informacion del proyecto.

## Unidades de medida utilizadas
Unidad:rem    se uso en. Tamaños de texto, espacios y bordes redondeados. 
 Unidad: px   se uso en. Bordes y puntos de corte de las pantallas. 
Unidad: %     se uso en.  Anchos adaptables. 
Unidad:  vh   se uso en.Altura de la portada. 
 Unidad: ch   se uso en.Ancho de lectura de los párrafos. 


 Celulares: una columna.
 Computadores: tres columnas desde 900 px.


## Decisiones de diseño

Se eligió una paleta de colores rosados  porque le da una identidad visual a la cafeteria. También se utilizaron tarjetas, imágenes, tablas y formularios para organizar la información y hacerla mas facil a los clientes.


## Dificultades y soluciones

Una de las dificultades que tuve fue organizar los elementos para que se adaptaran a diferentes tamaños de pantalla y esto  se solucionó utilizando CSS Grid.
